# Обычный Chrome без Playwright

Режим `chrome_extension` использует уже установленный обычный Google Chrome и его
обычный пользовательский профиль. Python не запускает Chrome через Playwright,
WebDriver или remote debugging. Расширение выполняет только одну текущую команду
локального загрузчика: открыть объявление, один раз нажать кнопку телефона, вернуть
DOM-номер либо снимок активной вкладки для локального OCR.

## Безопасность

- мост слушает только `127.0.0.1` и недоступен из локальной сети;
- каждый компьютер получает случайный 256-битный токен;
- токен хранится только в локальных `.env` и `chrome-extension/config.local.js`;
- `config.local.js` исключён из Git;
- расширение имеет доступ только к `avito.ru` и локальному мосту;
- одновременно выполняется только одна команда;
- CRM не затрагивается командой `avito-extension-test`.

## Установка

Закройте Chrome for Testing. Обычный Chrome можно оставить установленным и
использовать в привычном профиле.

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\scripts\install-chrome-extension.ps1
```

Скрипт откроет `chrome://extensions` и папку расширения. В Chrome:

1. включите **Режим разработчика**;
2. нажмите **Загрузить распакованное расширение**;
3. выберите папку `chrome-extension` из проекта;
4. убедитесь, что включено **Avito CRM Local Bridge**.

После обновления файлов проекта нажмите **Обновить** на странице
`chrome://extensions` в режиме разработчика. Загрузчик проверяет версию расширения
и не начнёт обработку со старым сценарием.

Перезагрузка Windows не нужна. Не копируйте `config.local.js` на другие компьютеры.

## Первый тест без CRM

Используйте объявление, которое только что успешно проверено вручную в этом же
обычном Chrome. На первом тесте разрешён один клик:

```powershell
.\.venv\Scripts\python.exe -m avito_crm avito-extension-test `
  "https://www.avito.ru/..." --max-clicks 1
```

Расширение само откроет одну вкладку и выведет её на передний план. Если Avito
покажет капчу, загрузчик:

1. не перезагружает страницу;
2. ожидает ручного решения в этой же вкладке;
3. после перенаправления продолжает ту же строку;
4. ждёт без ограничения времени до решения капчи либо команды STOP.

После получения номера команда печатает его источник и завершается без Google
Sheets и LPTracker.

## Возврат к Playwright

Локально замените в `.env`:

```dotenv
AVITO_BROWSER_DRIVER=playwright
```

Токен и конфигурацию расширения можно оставить для будущей диагностики. Не
удаляйте `.env.before-extension`, пока новый режим не прошёл контрольный запуск.
