# Обычный Chrome без Playwright

Режим `chrome_extension` использует уже установленный обычный Google Chrome и его
обычный пользовательский профиль. Python не запускает Chrome через Playwright,
WebDriver или remote debugging. Расширение выполняет только одну текущую команду
локального загрузчика: открыть объявление, один раз нажать кнопку телефона, вернуть
DOM-номер либо снимок активной вкладки для локального OCR.

## Безопасность

- мост слушает только `127.0.0.1` и недоступен из локальной сети;
- каждый компьютер получает случайный 256-битный токен;
- токен хранится только в локальных `.env` и `chrome-extension/config.local.js`;
- готовность объявления определяется по ID и фактически отрисованной области/кнопке:
  расширение не ждёт завершения фоновой загрузки всех ресурсов страницы;
- при сбое рендера выполняются не более двух загрузок одной и той же строки, а следующая
  команда принимается только после терминального результата текущей;
- `config.local.js` исключён из Git;
- content script запускается только на `avito.ru`, а снимок разрешён только после
  проверки ID управляемого объявления до и после захвата;
- Chrome требует разрешение `<all_urls>` для фонового `captureVisibleTab` без
  ручного клика по значку расширения. Расширение не использует это разрешение для
  других сайтов: перед снимком дважды проверяются активная вкладка, домен и ID объявления;
- OCR получает PNG самой вкладки и координаты области номера в CSS-пикселях. Масштаб
  вычисляется по реальному PNG, поэтому Windows DPI 125/150/200% не влияет на crop;
- PNG передаётся только в памяти через авторизованный `127.0.0.1`, ограничен по
  размеру и времени, не сохраняется на диск и не печатается в логах. В диагностику
  попадают только размеры, масштаб, тип области и короткий SHA-256;
- одновременно выполняется только одна команда;
- CRM не затрагивается командой `avito-extension-test`.

## Установка

Закройте Chrome for Testing. Обычный Chrome можно оставить установленным и
использовать в привычном профиле.

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\scripts\install-chrome-extension.ps1
```

Скрипт откроет `chrome://extensions` и папку расширения. В Chrome:

1. включите **Режим разработчика**;
2. нажмите **Загрузить распакованное расширение**;
3. выберите папку `chrome-extension` из проекта;
4. убедитесь, что включено **Avito CRM Local Bridge**.

После обновления файлов проекта нажмите **Обновить** на странице
`chrome://extensions` в режиме разработчика. Загрузчик проверяет версию расширения
и не начнёт обработку со старым сценарием.

Перезагрузка Windows не нужна. Не копируйте `config.local.js` на другие компьютеры.

## Первый тест без CRM

Используйте объявление, которое только что успешно проверено вручную в этом же
обычном Chrome. На первом тесте разрешён один клик:

```powershell
.\.venv\Scripts\python.exe -m avito_crm avito-extension-test `
  "https://www.avito.ru/..." --max-clicks 1
```

Расширение само откроет одну вкладку и выведет её на передний план. Если Avito
покажет капчу, загрузчик:

1. не перезагружает страницу;
2. ожидает ручного решения в этой же вкладке;
3. после перенаправления продолжает ту же строку;
4. ждёт без ограничения времени до решения капчи либо команды STOP.

После получения номера команда печатает его источник и завершается без Google
Sheets и LPTracker.

Для согласованной диагностики OCR можно добавить `--save-failed-captures`.
Только если все OCR-варианты завершатся ошибкой, точный PNG вкладки и JSON с
координатами/fallback будут сохранены в `output/ocr-failed-captures`. Успешные
кадры не сохраняются. PNG может содержать показанный телефон, поэтому каталог
остаётся локальным, исключён из Git и удаляется после завершения разбора.

## Объёмный OCR-тест без CRM и очереди

Команда `avito-extension-batch-test` предназначена только для настройки открытия и
распознавания номеров. Она читает ссылки из локального `.txt`, `.csv`, `.xlsx` либо
в read-only режиме из Google-очереди, держит один локальный мост и одну управляемую
вкладку обычного Chrome, но вообще не создаёт CRM-клиент и не вызывает методы записи
очереди. Телефоны и полные URL не попадают в отчёт. Для сопоставления с источником
сохраняются только порядковый номер строки и короткий SHA-256 ссылки.

Начинайте с 3, затем 20, затем 100 ссылок. К 200 переходите только если предыдущий
этап не показал системной ошибки. По умолчанию тест остановится после 10 одинаковых
последовательных OCR/Chrome-ошибок, чтобы не расходовать остальные ссылки при
регрессии. CAPTCHA не обходится: Chrome ждёт ручного решения или команды STOP.

Однострочная команда PowerShell:

```powershell
Set-Location D:\avito-crm; .\.venv\Scripts\python.exe -m avito_crm avito-extension-batch-test --google --sheet "Лист1" --status retry_phone --limit 20 --max-clicks 2 --circuit-breaker 10
```

Итоговый JSONL сохраняется в `output/extension-batch-*.jsonl`. В нём есть количество
проверенных ссылок, доля успешных открытий, классы ошибок, источник распознавания и
время каждой строки. Поля `crm_writes=false` и `queue_writes=false` дополнительно
фиксируют безопасный режим.

## Возврат к Playwright

Локально замените в `.env`:

```dotenv
AVITO_BROWSER_DRIVER=playwright
```

Токен и конфигурацию расширения можно оставить для будущей диагностики. Не
удаляйте `.env.before-extension`, пока новый режим не прошёл контрольный запуск.
