# Google Sheets и запуск без терминала

## Что получает оператор

На рабочем столе Windows есть ярлык **«Avito в CRM»**. В окне можно:

- вставить ссылку на Google-таблицу;
- указать точное название листа;
- выбрать JSON сервисного аккаунта Google;
- задать лимит новых лидов;
- проверить доступ без записи в CRM;
- запустить очередь или мягко её остановить;
- видеть живой журнал, капчу, ошибки и итог запуска.
- настроить Telegram-уведомления и многочасовое ожидание капчи.

Терминал для ежедневной работы не нужен.

## Одноразовая настройка Google

1. Создайте проект в Google Cloud и включите Google Sheets API.
2. Создайте service account.
3. В разделе **Keys** создайте новый ключ типа JSON.
4. Сохраните JSON вне `C:\avito-crm`, например
   `C:\ProgramData\AvitoCrm\google-service-account.json`.
5. В GUI нажмите **«Выбрать JSON»**. Программа покажет `client_email`.
6. Откройте Google-таблицу, нажмите **«Настройки доступа»**, добавьте этот email
   и выдайте роль **«Редактор»**. Уведомление отправлять не нужно.

Официальные инструкции:

- [Google: создание service account и JSON-ключа](https://developers.google.com/workspace/guides/create-credentials)
- [gspread: авторизация service account](https://docs.gspread.org/en/master/oauth2.html)

JSON содержит закрытый ключ. Его нельзя отправлять в чаты, загружать в GitHub или хранить
в папке репозитория.

## Таблица

В колонку **«Ссылка»** вставляются ссылки Avito. Если лист полностью пуст, первая проверка
сама создаст и закрепит строку заголовков:

```text
Ссылка | Статус | Телефон | CRM lead ID | Ошибка | Попытки | Обработано | Run ID
```

Если в непустом листе уже есть `Ссылка`, отсутствующие служебные колонки будут добавлены
справа. Другие колонки и данные не изменяются.

## Ежедневная работа

1. Добавьте новые ссылки вниз колонки `Ссылка`.
2. Закройте фильтры/редактирование строк и не меняйте их порядок во время запуска.
3. Откройте ярлык **«Avito в CRM»**.
4. Укажите лимит новых лидов.
5. Нажмите **«Запустить в CRM»** и подтвердите запуск.
6. Если Avito покажет проверку, очередь поставится на паузу и отправит Telegram-сообщение.
7. Зайдите на удалённый компьютер и завершите проверку в открытом Chromium. Нажимать
   кнопку в программе не требуется: GUI сам заметит решение и продолжит очередь.

Лимит считает **созданные лиды**. Дубликаты и ошибки его не расходуют. Если готовых строк меньше
лимита, запуск завершится после исчерпания таблицы.

## Остановка и продолжение

Кнопка **«Остановить»** не обрывает текущую строку: номер и CRM-запись доводятся до конца, после чего
новая строка не берётся. Следующий запуск продолжит очередь по статусам.

Одновременно может работать только один запуск.

Telegram настраивается в окне **«Капча и уведомления → Настроить Telegram»**.
Подробная одноразовая инструкция: [TELEGRAM.md](TELEGRAM.md).
