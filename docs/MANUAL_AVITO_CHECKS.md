# Ручная проверка Avito: предсказуемая схема работы

Эта инструкция относится к приложению 1.12.64 и расширению 1.0.31 при
AVITO_EXTENSION_INCOGNITO=true.

## Главное правило

Страница «Доступ ограничен: проблема с IP» с кнопкой **«Продолжить»** является
началом ручной проверки. Это не техническая ошибка и не завершение запуска.
Программа оставляет управляемую вкладку открытой, ставит очередь на паузу и ждёт
без ограничения времени до ручного решения либо штатной команды STOP.
После решения та же вкладка сохраняется: кратковременная домашняя страница Avito
проверяется повторно и не завершает текущую команду сама по себе.

## Уведомления для ассистентки

Есть только три вида сообщений. «Разгадайте капчу Avito» означает: открыть
управляемое окно, нажать «Продолжить» и пройти проверку. После этого ничего
не запускать: очередь продолжится сама. Если вместо капчи видно пустое окно
или после проверки очередь не продолжилась, ассистентка сообщает об этом
руководителю, а не перезапускает очередь наугад.

После решённой проверки всегда приходит итог: либо «Проверка Avito завершена.
Продолжаем обработку», либо «Очередь завершена. Доступных ссылок для обработки
не осталось». Второй вариант не требует перезапуска, даже если отдельные
технические строки сохранены в «Диагностике».

«Проверьте работу Avito» означает: посмотреть, продолжилась ли очередь; если
нет — перезапустить запуск через пульт. Причины и строки для разбора уже
сохранены в листе «Диагностика». Третий вид — информационный: ожидание
безопасного времени либо нормальное завершение. Он не требует действий.

Если полный запуск не нашёл ни одной доступной ссылки, это отдельное обычное
сообщение о пустой очереди: оно приходит один раз за 24 часа. Это правило не
касается капчи, технической проблемы и любого состояния, требующего действий:
для них остаётся настроенная цепочка напоминаний и эскалации.

## Что сотруднику делать нельзя

- Не закрывать управляемое окно во время ручной проверки.
- Не обновлять страницу серией повторных нажатий.
- Не ставить новую команду запуска после уведомления о паузе.
- Не считать пустую вкладку капчей: уведомление о ручной проверке отправляется
  только после обнаружения реальной страницы ограничения/авторизации.

## Признаки корректной работы

1. После уведомления о ручной проверке текущая команда остаётся активной.
2. В окне Chrome видна страница Avito, потребовавшая действие.
3. После решения приходит сообщение о продолжении.
4. Та же команда и та же строка продолжаются без новой галочки запуска.
5. Номер попытки строки не расходуется из-за ожидания или штатного STOP.
6. Если строка требует разбирательства, её причина и готовое действие находятся
   в листе Google-таблицы «Диагностика».
7. Во время работы остаётся одно управляемое окно инкогнито. Старые пустые окна
   и старые одно-вкладочные окна Avito закрываются автоматически.
