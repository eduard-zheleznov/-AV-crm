# Диагностика без PowerShell

В программе «Авито → CRM» нажмите **Собрать диагностику** справа от заголовка
«Ход работы». Кнопка доступна и во время обработки очереди. Через несколько
секунд программа покажет ZIP-файл в папке `output/diagnostics`. Передайте этот
один файл в чат поддержки; команды и скриншоты консоли не нужны.

В отчёте: версия программы, версия файлов расширения, фактическая версия
расширения при доступном локальном мосте, состояние контроллера/обработчика,
флаг STOP, наличие незавершённой команды, последние этапы и категории ошибок.

Нет: `.env`, исходных логов, базы/очереди, телефонов, CRM-идентификаторов,
получателей, паролей, токенов, cookie, личных путей, URL таблицы или объявлений.
Отчёт строится по списку разрешённых полей, а не удалением известных секретов
из произвольного текста. Недоступность локального моста при отсутствии рабочего
процесса ожидаема и сама по себе не является неисправностью.

Диагностика только читает состояние; не запускает очередь, не открывает Avito,
не расходует попытки, не создаёт лиды, не меняет настройки и не отправляет файл
никому автоматически. Необходимость ручного решения CAPTCHA остаётся.
Сбой Chrome или отсутствие интернет-связи не мешают сбору локального отчёта.

## Проверка и восстановление

Проверены отсутствующий конфиг, недоступный мост, повреждённые файлы состояния,
дубли нажатий (кнопка блокируется на время сбора), отдельные уникальные архивы
и исключение произвольных секретов из логов/ответов. При ошибке записи кнопка
возвращается в рабочее состояние. Архивы сохраняются только локально и не
попадают в Git.

Программа: 1.12.68. Расширение остаётся 1.0.33; отдельное обновление расширения
для этой кнопки не требуется. Закройте окно программы перед установкой и снова
откройте ярлык после неё. Откат: `baseline-20261009-diagnostics-report`.
