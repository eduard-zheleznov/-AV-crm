# Telegram-уведомления о капче (необязательный второй канал)

На текущем удалённом сервере соединение с `api.telegram.org:443` не проходит,
хотя DNS работает. Поэтому основной рабочий канал — SMTP/email: [EMAIL.md](EMAIL.md).
Telegram можно оставить настроенным: при восстановлении сетевого доступа программа
снова сможет использовать его без изменения логики очереди.

## Что происходит во время работы

Если Avito показывает капчу или ручную проверку, программа:

1. оставляет текущую ссылку и браузер открытыми;
2. сразу пишет основному ответственному;
3. по умолчанию повторяет сообщение через 30 минут;
4. через 60 минут пишет основным и резервным ответственным;
5. проверяет браузер каждые несколько секунд;
6. после ручного решения уведомляет о продолжении и снова открывает ту же ссылку;
7. только через 12 часов без решения завершает ожидание и сохраняет строку для повтора.

Интервалы `30,60`, резервные получатели и 12-часовой таймаут можно изменить в GUI.
Сбой Telegram не останавливает ожидание: программа отключает недоступный канал до конца
текущего запуска, продолжает следить за браузером и использует настроенный email.

## Одноразовая настройка

1. Откройте ярлык **«Avito в CRM»**.
2. В строке **«Капча и уведомления»** нажмите **«Настроить Telegram»**.
3. Нажмите **«Открыть BotFather»**, создайте бота командой `/newbot` и скопируйте токен.
4. Вставьте токен в поле **«Токен бота»**. Никому его не пересылайте.
5. Каждый человек, которому нужны сообщения, открывает созданного бота и отправляет `/start`.
6. Нажмите **«Найти Chat ID»**. Найденные ID появятся в журнале главного окна.
7. Вновь откройте настройки Telegram:
   - свой ID вставьте в **«Основные Chat ID»**;
   - ID подстраховывающего человека — в **«Резервные Chat ID»**.
8. Нажмите **«Отправить тест»**. Тест должен прийти всем указанным получателям.
9. Сохраните настройки.

Несколько ID указываются через запятую. Бот не может первым начать личный диалог: каждый
получатель обязан хотя бы один раз нажать **Start** или отправить `/start`.

Официальная документация: [Telegram Bot API — sendMessage и getUpdates](https://core.telegram.org/bots/api).

## Безопасность

- токен хранится только в локальном `C:\avito-crm\.env`, который исключён из Git;
- токен маскируется в журналах, включая технические HTTP-сообщения;
- не вставляйте токен в Google-таблицу, GitHub, скриншоты или переписку;
- если токен случайно опубликован, отзовите его через BotFather и создайте новый.
