# Безопасность и данные

- Телефонные номера и CRM ID являются рабочими данными. Они остаются только в
  исходной таблице и локальном `data/state.sqlite3`.
- Скриншоты ошибок могут содержать данные страницы Avito и автоматически
  исключены из Git. Удаляйте их после диагностики по внутреннему сроку хранения.
- `.env`, service-account JSON и браузерный профиль не копируются в Git/backup
  кода. Профиль может содержать cookies авторизованного аккаунта; доступ к
  Windows-профилю должен быть ограничен оператором. Выход из Avito через кнопку
  **«Открыть профиль»** сохраняет гостевое состояние для следующих запусков.
- Пароль, переданный через чат, следует заменить перед production-запуском.
- В логах телефон маскируется. Пароль и LPTracker token не логируются.
- CRM изменяется только при явном `--live`; `doctor`, `crm-check` и `capture` не
  создают лиды.
- Система не решает CAPTCHA и не применяет stealth/proxy/fingerprint-обходы.
  Использование должно соответствовать правилам Avito, правовым основаниям
  обработки контактных данных и внутренней политике компании.
